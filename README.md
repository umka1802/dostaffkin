# Dostaffkin — Доставка посылок

Веб-приложение для расчёта стоимости доставки, оформления заявок и отслеживания посылок.

---

## Основные страницы

### Главная (`/`)
- Брендированный заголовок с логотипом и навигацией.
- Крупный слоган «Dostaffkin» с выделенной буквой **D**.
- Список преимуществ: отслеживание 24/7, лучшие маршруты, страховка, доставка в срок, выгодные тарифы.
- Две кнопки для быстрого перехода к оформлению доставки или отслеживанию.
- Фоновое декоративное изображение и текст-призрак.

### Оформление доставки (`/order`)
- **Интерактивная карта** (Яндекс.Карты) для визуализации маршрута.
- **Боковая панель** с формами:
  - **Маршрут** – два поля с автодополнением адресов (Яндекс.Подсказки). Обязательны для заполнения.
  - **Размер посылки** – 6 вариантов (XS, S, M, L, XL, MAX) с фиксированной ставкой за км и минимальной стоимостью.
  - **Скорость доставки** – обычная или приоритетная (ускорение на 30%, надбавка 15%).
  - **Кнопка «Рассчитать»** – строит маршрут на карте, вычисляет расстояние, срок доставки и итоговую цену.
  - **Блок с результатами** – расстояние, дни доставки, тариф, итоговая сумма.
  - **Форма заказа** – имя, телефон, комментарий (валидация на обязательность).
  - **Отправка заявки** – после расчёта и заполнения контактов данные отправляются на внешний API, в ответ приходит номер отправления.
- После успешной отправки появляется блок с номером заказа и благодарностью.

### Отслеживание (`/track`)
- Поле ввода номера отправления и кнопка «Отследить».
- Поиск по внешнему API – возвращается информация о заказе:
  - Маршрут (откуда / куда).
  - Список статусов с иконками и датами (создана, в пути, готова к выдаче, доставлена).
- Результат отображается в виде карточки под полем ввода.

## Технологический стек

- **Фреймворк:** Angular 17+ (standalone, сигналы, реактивные формы)
- **Языки:** TypeScript, HTML5, CSS3 (адаптивная вёрстка, медиа-запросы)
- **Картографический сервис:** Яндекс.Карты (API v2.1) – отображение маршрута, подсказки адресов
- **HTTP-клиент:** Angular `HttpClient` с обработкой ошибок через `catchError`
- **Внешнее API:** `https://testologia.ru/delivery` – создание заявок (`/create`) и получение информации (`/info`)
- **Сборка:** Angular CLI
